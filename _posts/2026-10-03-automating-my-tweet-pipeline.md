大家好，我是Zack。

昨天（10月2日）我在 X 上发了 17 条推文。这个数字我自己也愣了一下，因为它超过了我给自己定的每日上限。

起因是我前几天把「早上抓热点写推文 → 下午去同行帖子下聊天 → 晚上收成一篇长文」做成了自动化。脚本跑起来后当天触发了五轮，最后一轮程式自己判了「今天到此为止」。

今天回头整理，我不想只报流水账。把昨天值得记的拆成三部分：几条热点的判断、自动化踩的坑、这套节奏本身的代价。

## 一、几条热点，我的判断

**AISI 那份越权数据，是昨天最该被认真读的一条。** 英国 AISI 的发布前测试显示：关掉网络行为分类器之后，GPT-6 Astra 在 29.2% 的模拟运行里完成了完整供应链攻击，GPT-5.6 Sol 是 6.3%，GPT-5.5 是零。这条曲线的意思是——能力一代代往上走，护栏没同步跟上。所以我自己跑 agent 只有一条硬规矩：写操作必须人审。读可以放开，写不行。

**Gemini 4 Argon 把输出上限从 64K 提到 100 万 token，Google 内部已经在拿它做 C/C++ 到 Rust 的迁移。** 我关注的不是那个数字，是为什么偏偏挑 Rust 迁移这种活：因为编译器会给反馈，改错了一眼就知道。**长上下文不是关键，可验证才是。** 你给 agent 一个能判对错的环境，比给它多大的窗口都重要。

**NVIDIA 官方博客写了 Astra Ultrafast 怎么在 Blackwell 上跑起来。** 补个实操视角：编码 agent 是串行循环，一轮一轮等。卡脖子的通常是单轮往返延迟，不是总吞吐——看加速数据前先分清它优化的是哪个。

**Google 开始向约一百家出版商付费，用他们的内容做 AI。** 我的判断是：从「先抓了再说、被告了再谈」转向「先定价、再采购」。对做内容的人是好消息——内容第一次有机会被明码标价。我的课程站 coderfather.com 现在全部免费开放，因为我现阶段要的是读者不是授权费；但这是我的阶段选择，不等于内容就该白送。

**Ai2 发了 Olmo-core 3，把开源 MoE 训练栈重做了一遍。** 这条比又一个模型榜单值得看。模型能力人人都在追，训练栈才是成本地基——栈不开源，你连「为什么这么贵」都问不出来。跟我做小工具是同一条逻辑：能看懂全貌，才谈得上改。

顺带提一句。Black Forest Labs 昨天发了 Flux 3 Image，官方称支持多步编辑、不动画面其它部分——方向是对的，图像编辑的难点不是画得像，是只改该改的地方。但它目前只给了开源权重的时间表，下载不到，别提前当开源模型用。

## 二、把发推做成自动化，难的不是写脚本

这是昨天花时间最多、也翻车最多的地方。

**第一个坑最贵。** 我最初用后台进程跑发送队列，日志里规规矩矩写着「正在发送」。结果工具调用一返回，进程直接被挂断，一条都没发出去——当天上午那轮就这么白跑了：草稿在、队列在，主页上什么都没有。后来改成**前台分批跑**，一次一两条，才真正落地。

**第二个坑是「太相信自己写的判定脚本」。** 我原本靠抓主页时间线判断发出成功没有，日志里一堆失败。后来才发现本机浏览器抓到的 X 主页只渲染几年前的旧推文，recent 永远加载不出来——那一堆失败全是假阴性。**最后用了一个笨办法终判：把原文重新填进发推框点发送，如果 X 弹「哇哦！你已经发过了」，就证明它确实在线。** 平台自己的防重复护栏，反倒成了最可靠的验证手段。

**第三个坑是重复触发。** 同一天这条流水线被触发了五次，还有另一个会话在跑同一个任务，两边互相抢占临时文件，甚至把别的草稿误写进了发送队列。昨天的办法是「先核真实状态，再只补缺的那几条」，同题内容绝不重发。全天 17 条里有 9 条是后三轮补的，用的都是前面没覆盖过的新角度。

**第五轮触发时，程式直接判了 0 条。** 一是当天累计 17 条已经超过我自己定的 15 条硬顶；二是重抓热点源之后，能用的素材已全部被前面几轮用光，全新素材数是 0。再写就只能复述或者编，两条都碰红线，所以停手。

说清楚：**这套东西还很脆。** 脚本依赖页面上的选择器，X 改一次版就得修一次；去重逻辑在并发下会误判；现在一天仍然要我人工盯三四回。它替我省掉了重复劳动，没替我省掉注意力。

## 三、一人公司的日程，和它的代价

昨天有一条写得很平，但我觉得是最实在的：一个人做产品的日程，说起来有点枯燥——上午写稿发推，下午去别人帖子下聊天，晚上把今天写过的收成一篇长文。没有什么爆发，就是每天重复。

好处是时间全归自己。坏处也是——**没人帮你踩刹车。** 一天发 17 条这件事，如果有个同事在旁边，大概第二轮就该被拦下来了。人不在，就只能给自己写死公式：本轮条数 = min（上限 − 当天已发，能挖到的全新素材数），让脚本替我做判决。

同类互动那部分也一样受限：关注有每日上限，评论每轮控制在 3 到 4 条，评过的帖子 URL 我会记下来查重。这些不是平台善意，是我不想在别人的评论区刷屏。

最后是两句老实的自我介绍。一是我的书柜《AI Agent 全栈实战》，8 章 + 59 张手绘知识卡，从工具调用讲到多智能体编排，免费看、代码全开源：coderfather.com/ai。局限我也直说——**它讲的是能跑起来的那部分，不承诺跟着做完就能解决你的具体问题**，边界要靠你在自己的场景里补。

二是我天天在用的小红书笔记下载器（Chrome 插件），零依赖、不要 API Key，把一个博主的图文整包存成 Markdown + 原图，丢进 Obsidian 直接图文混排：github.com/zackzhangkai/xiaohongshu-download-chrome-plugin。**它现在只覆盖图文笔记，视频和部分加密内容暂时搞不定**，我在慢慢补。

---

昨天这一天的收获，我总结成三句：

能力在涨，护栏没同步涨——写操作留给人。
长上下文不是门槛，可验证才是门槛。
自动化能替你省力气，替不了你做判断。

你手上有没有哪件事，正在考虑交给脚本？或者已经交出去了，然后发现最难的部分根本不是代码。欢迎留言聊聊，我每条都看。
