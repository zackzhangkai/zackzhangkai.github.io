CLI 命令一览
# 安装 CLI
npm install -g uipro-cli

# 安装技能到指定 AI 助手
uipro init --ai opencode
uipro init --ai claude
uipro init --ai cursor
uipro init --ai all          # 全部

# 选项
uipro init --offline         # 跳过 GitHub 下载，使用本地资源
uipro init --force           # 强制覆盖已有文件

# 其他命令
uipro versions               # 查看可用版本
uipro update                 # 更新到最新版
uipro uninstall              # 卸载技能（自动检测平台）
uipro uninstall --ai claude  # 卸载指定平台
uipro uninstall --global     # 卸载全局安装
⚙️
工作原理
  1. 运行 uipro init --ai <platform>
  2. CLI 检测当前平台（扫描 .cursor/、.claude/ 等）或使用 --ai 参数
  3. 默认模式（Template）：从内置模板动态生成平台专属技能文件
  4. 旧版模式（--legacy）：从 GitHub Releases 下载 ZIP 并解压
  5. 若 GitHub 下载失败（限流/网络），自动回退到 CLI 内置资源包
  6. 技能文件夹被放置到对应平台的配置目录（如 .claude/skills/ui-ux-pro-max/）
